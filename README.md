# odoo_debug_always

Chrome/Edge/Firefox extension that automatically enables `?debug=1` on every Odoo page.

See [`OdooDebug-Always/README.md`](OdooDebug-Always/README.md) for full documentation and [`OdooDebug-Always/CHANGELOG.md`](OdooDebug-Always/CHANGELOG.md) for change history.

## Load in Chrome

1. `chrome://extensions` → Developer mode → Load unpacked
2. Select the `OdooDebug-Always/` folder
